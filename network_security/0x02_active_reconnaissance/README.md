# Active Reconnaissance Task

This project covers the fundamental principles of network reconnaissance. The goal is to perform authorized scanning and analysis on a target machine to identify open ports, services, and potential vulnerabilities.

## Tasks Performed

1.  **Port Scanning (0-ports.txt):**
    * Conducted network scanning using `nmap` to identify open ports on the target machine.
    * Documented the identified open ports in `0-ports.txt`.

2.  **Vulnerability Assessment (2-injectable.txt):**
    * Explored the application by manipulating parameters, forms, and queries to identify potential injection vulnerabilities.
    * Recorded the identified vulnerable path in `2-injectable.txt`.

## Tools Used
* **Nmap:** For network discovery and security auditing.
* **Git:** For version control and submission management.

## Notes
* All activities were performed within the authorized Sandbox environment.
* File formats strictly adhere to the project requirements (e.g., proper encoding and newline usage).
