# 0x05 - Upload Vulnerabilities

## Overview
This module focuses on identifying and exploiting insecure file upload vulnerabilities in web applications.

## Target
- **Domain**: `http://web0x05.hbtn`
- **Target Subdomain**: `test-s3.web0x05.hbtn`

## Tasks
